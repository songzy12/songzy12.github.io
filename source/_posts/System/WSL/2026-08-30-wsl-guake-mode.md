Configure a Windows Terminal shortcut to toggle Quake mode.

## Shortcut

1. Open Windows Terminal and select `Settings` from the drop-down arrow next to the New Tab button.
2. Select `Actions` in the left sidebar.
3. Find `Show/hide quake window` in the action list. Select its existing keybinding to edit it, or select `Add new` and choose `Show/hide quake window`.
4. Click the keybinding field and press the key combination to use, for example `Win + Backtick`.
5. Select the checkmark to save the action, then select `Save`.

Press the configured shortcut to show or hide the Quake window.
